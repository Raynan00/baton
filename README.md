# Baton

Continuity for everyone: Handoff, Universal Clipboard and file drop across iPhone, Windows and Linux.
Direct over the LAN when possible, through a small end-to-end encrypted Cloudflare relay otherwise.

The spec is [`BATON.md`](BATON.md); build status is in [`PROGRESS.md`](PROGRESS.md).
